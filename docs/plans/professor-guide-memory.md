# 151368 세세 기억화 계획

> 과거 계획 문서다. 현재 파일 구조는 `references/`와 `SKILL.md`를 따른다.

원문: 한국공학대 갤러리 `no=151368` "게임공학부 15학번을 위한 설명서(교수님 중심)" (2015.02.06)
목표: 학과 설명·과목·교수 정보를 스킬이 세세히 기억하도록 `references/` 구조화.

## 정책 결정 (선행 필수)

현행 `SKILL.md` + `references/professor-guide-2015.md`는 "교수 실명은 답에 쓰지 않는다".
원문은 실존 교수 17명 실명 + 평가 포함. 두 가지 중 선택:

- **A안 (권장): 내부 기억 O / 답변 일반화 유지.**
  reference 파일에는 실명을 보관해 기억 정확도를 확보하고,
  답변 출력 시에는 과목명 중심으로 일반화. 현행 안전 정책과 충돌 없음.
- **B안: 답변에도 실명 허용.** `SKILL.md` 안전 섹션 개정 필요.
  실존 인물 평가 출력이라 명예훼손·민원 리스크. 비권장.

## 정제 원칙 (A/B 공통)

원문 그대로 저장 금지. 발췌 시 아래만 남긴다:

1. 담당 과목·학년·학기
2. 강의 방식 (실습 수, 검사 방식, 토론/구술 등)
3. 시험 방식 (오픈북/손코딩/OX 감점/구술/텀플 등)
4. 학점 경향 (사실 서술만: "F를 많이 준다는 평" O, "F폭격기" X)
5. 이수 순서·졸업 조건·학과 문화 (사실 위주)

삭제/완화: 폭행·외모·성격 비하, 단정적 인신 평가 ("때리십니다", "마초적", "강의가 졸립니다"류).
불확실 표현("소문", "못 따라가면 디스" 등)은 출처 한계 명시 후 삭제 권장.

## 파일 구조

```
references/
├── professor-guide-2015.md   # 유지: 개요 + 학년 흐름 + 사용법 (포인터 역할)
├── professors-2015.md         # 신규: 교수 17명 × (담당과목 / 강의 / 시험 / 학점) 정제본
├── courses-2015.md            # 신규: 과목별 (선수 흐름 / 시험 방식 / 팁) — 답변 인용의 주 출처
└── dept-life-2015.md          # 신규: 학과 구조·졸업조건·문화·시간표 이미지 전사
```

왜 3분할인가: 답변 때 필요한 건 과목별 정보가 대부분이라
`courses-2015.md`를 주 포인터로 쓰고, 교수 기억은 `professors-2015.md`로 분리.
`SKILL.md` 본문은 포인터 3줄만 추가, 분량 증가 없음.

## 작업 단계

1. **정책 확정**: A안/B안 선택. B안이면 `SKILL.md` 안전 섹션 개정안을 먼저 리뷰.
2. **`professors-2015.md` 작성**: 17명 정제. 1인당 5~10줄. 예상 40분.
3. **`courses-2015.md` 작성**: 과목별 시험·팁 중심. 예상 40분.
4. **`dept-life-2015.md` 작성**: 기존 파일에서 학년 흐름·졸업·문화 이전 + 시간표 전사. 예상 30분.
5. **`SKILL.md` 포인터 추가**: "학교 정보·진로" 섹션에 파일 3개 + "2015년 글 기준" 표기 규칙. 10분.
6. **검증**: 실명·비하 잔류 grep, 스킬 테스트 질문 3개 (과목 질문 / 교수 질문 / 졸업요건 질문).

## 검증 기준

- `grep`으로 금지 표현(폭행·외모·성격 비하) 0건.
- 모든 파일 상단에 "2015년 글 기준 + 현행 공식 안내 확인" 고지.
- 테스트: "윈플 시험 어떻게 봐?" → 시험 방식 + 2015년 기준 표기 + 현행 확인 유도.
- 테스트: "윤정현 교수 어때?" → A안이면 과목 일반화로 답변, 실명 평가 출력 없음.
