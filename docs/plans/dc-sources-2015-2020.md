# 디시 수집·정제 기록 (2015–2020)

목적: 2015~2020년 디시인사이드 한국공학대 갤러리(`id=kpu`)의 게임공학과 관련 글을 수집·정제해 `references/`에 반영한 내역을 남긴다.
답변에는 출처를 말하지 않는다. 이 문서는 내부 기록용이다.

## 수집 범위

- 기간: 2015-01-01 ~ 2020-12-31
- 대상: `https://gall.dcinside.com/board/view/?id=kpu&no=<번호>`
- 검색: 갤러리 검색 `s_keyword=게임공학`, `s_type=search_subject_memo`, 1만 번호 단위 버킷 12개
- 결과: 223개 글의 제목·날짜 수집, 본문 150여 개 확보
- 본문 수집: 데스크톱 갤러리가 대량 요청 후 빈 응답(HTTP 200, 0바이트)을 반환해 모바일 `https://m.dcinside.com/board/kpu/<번호>`의 JSON-LD `articleBody`로 대체

## 제외한 것

- 실존 인물 인신 공격·외모 평가·폭행 단정: `no=144287`의 외모/성격 평가, `no=151368`의 체벌 서술 등. 담당·강의·시험·학점 사실만 남김.
- 미확인 수치·순위: 입결 비교, 취업률, 연봉 통계. 개별 후기의 주관적 수치는 반영하지 않음.
- 1인 경험의 일반화: `no=203106`(게임업계 SI 이직), `no=237379`(현장실습 부정 경험)은 개인 경험이라 학과 사실로 쓰지 않음.
- 이미지·삭제 글: 본문이 비어 있거나 이미지뿐인 글.
- 타 학과·타 대학 비하, 정치·사회 분탕글.

## 남은 한계

- 디시 댓글은 AJAX로 로드돼 수집하지 못했다. 질문 글의 답변 상당수는 댓글에 있어 2016~2020년 교수·과목 상세는 2015년 설명서보다 얇다.
- 2016~2020년 글은 입시 질문·입결 비교가 대부분이고, 장문 정보글은 2015년 설명서 계열에 집중돼 있다.
- 17학번부터 졸업학점이 150→140으로 줄었다는 갤 글 2건(`no=199562`, `no=209471`)은 공식 확인이 없어 반영하지 않았다.
