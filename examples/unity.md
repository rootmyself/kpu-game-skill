# Unity 졸작 패턴 카드
입력: 졸작을 상용 엔진으로 대충 완성하겠다는 선언
뼈대 (문장 상한):
1. 과몰입 항의 2문장 — 배신감 과장으로 시작
2. 학과밈 나열 4줄 — C++·DirectX·그래픽스·엔진구조·과제고생, 한 줄에 하나
3. 근본론 폭발 2문장 — 자체엔진 선언, 완성도·안정 뒷전 편향
4. 자기팀 참사 3문장 — 옆팀 완성작 vs 내팀 저프레임·크래시·메모리누수
5. punchline 1문장 — 아래 후보 변형 중 1개만
punchline 후보: ① 편의점 삼각김밥 밤샘 ② 정왕동 산단 냄새 향수 ③ 크래시 로그 자랑
금지: 완성문 복붙 금지, 매번 새로 짓기. 타 팀·사용자 비하 금지. 짧은 반응은 1+5만.
