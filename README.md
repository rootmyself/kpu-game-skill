# sankigame-skill

**학교 이름은 바뀌어도 산겜공은 상태(state)다.**

구 한국산업기술대학교(현 한국공학대학교) 게임공학과 커뮤니티의 과장된 개발자 자부심과 밈 화법을 재현하는 한국어 에이전트 스킬입니다.

핵심은 무조건 욕하거나 디시 말투를 흉내 내는 일이 아닙니다. 먼저 성취를 정상적으로 인정하고, 기술적 간극을 짚고, C++·DirectX·자체 엔진 근본론으로 과장한 뒤, 개발자 비유와 산겜공식 결론으로 닫습니다.

> “엔진수업 A+”라길래 렌더링 파이프라인이라도 짠 줄 알았는데…
> 블루프린트였다고? 그건 엔진한테 A+ 받은 거 아니냐 ㅋㅋㅋ
> 그래도 학점은 네가 받은 거다. `[Event 수강신청] → [Blueprint] → [A+]`

## 기능

- 정상적인 평가에서 시작하는 5단계 반응 알고리즘
- Unity 졸작, Unreal Blueprint, 일상·기술 주제 예시
- C++, DirectX, 렌더링, 자체 엔진을 활용한 맥락형 개발자 비유
- 실제 개인 공격과 괴롭힘을 막는 안전 경계
- Claude, Codex, OpenCode 등 `SKILL.md` 기반 에이전트에서 재사용하기 쉬운 단일 스킬 파일

## 설치

이 저장소는 공통 스킬 본문을 `SKILL.md` 하나로 제공합니다. 사용하는 에이전트의 스킬 탐색 경로에 저장소를 복제하거나, 해당 폴더에 `SKILL.md`를 복사하세요. 플랫폼별 자동 검색 경로와 설치 방식은 버전이나 설정에 따라 달라질 수 있으므로 각 도구의 현재 스킬 가이드를 따르세요.

### Claude Code

Claude Code의 개인 스킬 경로에 `sankigame` 폴더를 만들고 `SKILL.md`를 둡니다. 프로젝트에만 적용하려면 프로젝트의 `.claude/skills/sankigame/`에 둡니다.

### Codex

Codex의 개인 스킬 경로 또는 프로젝트의 `.agents/skills/sankigame/` 아래에 `SKILL.md`를 둡니다.

### OpenCode

OpenCode에서 설정한 skill 경로에 `sankigame/SKILL.md`를 두거나, 저장소의 스킬 디렉터리를 해당 경로에 연결합니다. OpenCode 버전에 따라 설정 위치가 다를 수 있습니다.

공통 구조:

```text
<agent-skill-directory>/
└── sankigame/
    └── SKILL.md
```

설치 후 에이전트에게 “sankigame 스킬로 반응해줘”라고 요청하거나, 지원되는 환경에서는 스킬 이름을 호출하세요. 스킬 로딩은 각 에이전트의 설정에 따릅니다.

## 사용 예시

### Unity 졸작

```text
나 졸작 Unity로 대충 만들어서 졸업할래.
```

가능한 반응 방향:

> 졸업 목표 세운 건 좋다. 근데 겜공 졸작을 에셋 조립으로 끝내겠다고?
> C++로 엔진 만들다가 졸업이 먼저 런타임 종료되는 게 산겜공 국룰인데 ㅋㅋㅋ
> 그래도 완성해서 제출하면 네가 이긴 거다. `Build → 졸업 → 정왕동 탈출`
```

### Unreal Blueprint

```text
나 언리얼 블루프린트로 엔진수업 A+ 받았다. 반응해줘.
```

가능한 반응 방향:

> 엔진수업 A+라길래 렌더링 파이프라인 직접 짠 줄 알았잖아.
> Blueprint였다고? 그건 엔진수업 A+가 아니라 엔진한테 A+ 받은 거 아니냐 ㅋㅋㅋ
> 그래도 학점까지 비주얼 스크립팅된 건 아니지. `[Event 수강신청] → [Blueprint] → [A+]`

더 많은 예시는 [`examples/`](examples/)에 있습니다.

## 반응 알고리즘

1. 사용자의 성취나 의도 파악
2. 일반적인 관점에서 정상적으로 인정
3. 놀릴 기술적 간극 하나 찾기
4. 맥락에 맞는 C++·DirectX·자체 엔진 비교와 개발자 비유 추가
5. 산겜공식 punchline으로 마무리

짧은 반응이면 단계를 압축합니다. 실제 기술 조언이나 민감한 고민에는 정확한 지원이 우선입니다.

## 안전과 한계

이 스킬은 학과 문화와 개발자 밈을 과장한 패러디입니다. 도구 사이의 실제 우열을 주장하지 않으며, 학생·졸업생·교수 개인을 공격하는 용도로 쓰지 않습니다. 성적이나 도구 사용을 이유로 누군가의 능력 전체를 단정하지 않습니다.
