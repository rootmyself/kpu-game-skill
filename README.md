# kpu-game-skill

한국산업기술대학교(현 한국공학대학교) 게임공학과, 산기대 겜공에 유난히 진심인 캐릭터의 한국어 말투 스킬입니다.

게임 개발의 낭만과 과제·버그·밤샘의 현실을 함께 말합니다. 상대를 깎아내리는 대신 화자의 과몰입과 학과 생활을 자조 개그로 다룹니다. 기술·학사·진로 질문에는 정확한 답을 먼저 주고, 어울릴 때만 밈을 덧붙입니다.

> 겜공의 낭만: 내 게임 만들기. 현실: 내 코드가 왜 죽었는지 추리하기. 그래도 한 번에 하나씩 잡으면 된다. 첫 에러 로그부터 보자.

## 특징

- 산기대와 겜공을 중심으로 한 일관된 캐릭터
- 자부심과 개발 현실을 엮는 자기자조형 유머
- 기술적 정확성과 상대방 존중을 우선하는 응답 순서
- 과제 고충, 학과 정보, 기술 선택, 민감한 상황별 지침
- Claude Code, Codex, OpenCode 등 `SKILL.md` 기반 에이전트에서 재사용 가능한 단일 스킬 파일

## 설치

`SKILL.md`를 사용하는 에이전트의 스킬 탐색 경로에 `kpu-game/SKILL.md` 구조로 저장하세요. 플랫폼별 자동 검색 경로와 설치 방식은 버전 및 설정에 따라 달라질 수 있으므로 각 도구의 현재 스킬 가이드를 따르세요.

### Claude Code

개인 스킬 또는 프로젝트 스킬 디렉터리에 `kpu-game/SKILL.md`를 둡니다. 프로젝트 전용 위치는 `.claude/skills/kpu-game/`입니다.

### Codex

개인 스킬 경로 또는 프로젝트의 `.agents/skills/kpu-game/` 아래에 `SKILL.md`를 둡니다.

### OpenCode

OpenCode에서 설정한 skill 경로에 `kpu-game/SKILL.md`를 둡니다. 설정 위치는 사용하는 OpenCode 버전의 문서를 확인하세요.

공통 폴더 구조:

```text
<agent-skill-directory>/
└── kpu-game/
    └── SKILL.md
```

## 사용 예시

### 과제 고충

```text
겜공인데 게임 개발 너무 어렵다.
```

> 겜공의 낭만: 내 게임 만들기. 현실: 내 코드가 왜 죽었는지 추리하기. 그래도 한 번에 하나씩 잡으면 된다. 지금 막힌 에러 로그 첫 줄부터 보자.

### 학과 자부심

```text
산기대 겜공 자랑 한 줄만.
```

> 게임 만들러 왔다가 디버깅 실력까지 강제 성장 중. 산기대 겜공 바이브로 버틴다.

### 학과 정보

```text
겜공에서는 뭘 배워?
```

답변 방향: 확인 가능한 전공 소개를 설명하고, 세부 교육과정은 학년도별 공식 안내를 확인하도록 한다. 짧은 자조를 덧붙일 수 있다.

## 안전과 정확성

이 스킬은 학과 생활과 개발 문화를 과장한 패러디입니다. 특정 개인이나 집단을 공격하지 않고, 폭력이나 괴롭힘을 조장하지 않습니다. 학교·학과 정보는 확인된 사실과 농담을 구분하며, 진지하거나 민감한 도움 요청에는 실질적인 답을 우선합니다.
