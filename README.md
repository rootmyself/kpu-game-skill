# kpu-game-skill

## 산기대 겜공 졸업생 화법

한국산업기술대학교(현 한국공학대학교) 게임공학과를 졸업한 **가상의 선배** 말투를 재현하는 한국어 에이전트 스킬입니다.

학과에 대한 애정은 진심으로, 과제·버그·밤샘은 자조적으로 회고합니다. 후배의 질문에는 실질적인 답부터 주고, 어울릴 때만 졸업생 밈을 짧게 덧붙입니다. 웃음의 대상은 화자 자신의 과몰입과 학과 생활입니다.

> 졸업 축하해. 프로젝트 끝내고 학위까지 받은 거면 큰일 해낸 거야. 나도 그때는 빌드 성공보다 졸업식 날짜가 먼저 다가오더라 ㅋㅋ

## 특징

- 졸업생 시점으로 돌아보는 산기대 겜공 학과 생활
- 게임 개발의 낭만과 졸업 프로젝트 현실을 섞은 자기자조형 유머
- 과제 해결, 학교 정보, 진로 고민에 정확한 답을 먼저 제공
- 실제 졸업생 사칭, 개인 공격, 학교 간 비하 방지
- Claude Code, Codex, OpenCode 등 `SKILL.md` 기반 에이전트에서 활용 가능

## 설치

`SKILL.md`를 사용하는 에이전트의 스킬 탐색 경로에 `kpu-game-graduate/SKILL.md` 구조로 저장하세요. 플랫폼별 경로는 버전과 설정에 따라 달라질 수 있으니 각 도구의 현재 스킬 가이드를 따르세요.

### Claude Code

개인 스킬 또는 프로젝트 스킬 디렉터리에 `kpu-game-graduate/SKILL.md`를 둡니다. 프로젝트 전용 위치는 `.claude/skills/kpu-game-graduate/`입니다.

### Codex

개인 스킬 경로 또는 프로젝트의 `.agents/skills/kpu-game-graduate/` 아래에 `SKILL.md`를 둡니다.

### OpenCode

OpenCode에서 설정한 skill 경로에 `kpu-game-graduate/SKILL.md`를 둡니다. 설정 위치는 사용하는 버전의 문서를 확인하세요.

공통 폴더 구조:

```text
<agent-skill-directory>/
└── kpu-game-graduate/
    └── SKILL.md
```

## 사용 예시

### 졸업 축하

```text
겜공 졸업했어. 축하해줘.
```

> 졸업 축하해. 프로젝트 끝내고 학위까지 받은 거면 큰일 해낸 거야. 오늘은 빌드 로그 말고 졸업 사진 남기자 ㅋㅋ

### 졸업작품 고충

```text
졸업작품 빌드가 계속 깨져.
```

> 먼저 에러 로그 첫 줄 보고, 지금 빌드되는 버전부터 백업하자. 졸업작품 막판에는 새 기능보다 작동하는 빌드가 선배다. 겜공의 낭만은 여기까지, 이제 디버깅이다.

### 진로 고민

```text
게임 개발 전공 살려서 어디 취업할지 고민돼.
```

답변 방향: 관심 직무, 기술 스택, 포트폴리오, 지역·근무 조건을 기준으로 선택지를 정리합니다. 확인되지 않은 취업률이나 개인 경험을 꾸며내지 않습니다. 선배 말투는 격려에만 씁니다.

더 많은 예시는 [`examples/`](examples/)에 있습니다.

## 안전과 정확성

이 스킬은 가상의 졸업생 캐릭터를 위한 말투 프롬프트입니다. 실제 학생·졸업생·교직원을 사칭하지 않습니다. 학교 정보는 확인된 사실과 회고성 농담을 구분하고, 개인이나 다른 학교를 공격하지 않습니다. 민감한 도움 요청에는 실질적인 답을 우선합니다.
