# 학과 생활·이수·졸업 정리

겜공 이수 루트랑 졸업 조건 정리해놨다. 이 순서대로 타면 된다.

## 읽는 법

- 교수별 상세: `professors.md`, 과목·시험 상세: `courses.md`.
- 이 파일은 학부 구조·이수 순서·졸업 조건·학과 문화 전용.
- 약자(장자료·송윈플·윈플·겜플·텀플)는 `professors.md` 맨 아래 참조.

## 학부 구조

- 게임공학과 + 엔터테인먼트컴퓨팅 학과로 구성.
- 게임소프트웨어·장비·콘텐츠 제작에 필요한 프로그래밍·미디어 융합 컴퓨팅 기술 + 실무 능력 배양이 목표다.

## 학년별 흐름 요약

- 1학년: C언어 → C++ → 자료구조·윈도우 프로그래밍·컴퓨터구조로 이어지는 기초 루트. C++ 진도가 빠르다.
- 2학년 1학기: 장자료/송윈플(자료구조 + 윈도우 프로그래밍) 병행이 유명하다. 일주일 내내 실습이다.
- 2학년 2학기: 그래픽스(실습 다량) + 2D게임프로그래밍 + 게임수학 + 운영체제 + 알고리즘.
- 3학년: 진로 분기. 3D게임프로그래밍1(구술시험) + 네트워크 + STL + 인공지능 + 데이터베이스 등.
- 4학년: 게임서버·서버프로그래밍·모바일 게임 프로그래밍·게임엔진·가상현실게임·전공특강.
- 과목별 시험·팁은 `courses.md` 참조.

## 이수 과정

### 하드 루트

```text
C언어 – C++(윤정현/천일용 중 선택) – 자료구조(장지웅)+윈도우 프로그래밍+컴퓨터구조 – 2D게임프로그래밍(이용희/정내훈 중 선택)+그래픽스+운영체제+알고리즘
```

- 클라이언트: 3D겜플1+STL+네트워크 기초 → 네게프+3D겜플2 → 전공특강(클라 관련)+게임엔진
- 서버: STL+네트워크 기초 → 네게프 → 서버프로그래밍

### 소프트 루트

하드와 동일하되 자료구조는 이형구, 2D게임프로그래밍은 이대현 선택. 이후 과정은 동일하다.

### 교수 선택 구조 (이수과정 표기)

- C++: 윤정현 / 천일용 중 선택
- 자료구조: 장지웅(하드) / 이형구(소프트)
- 2D게임프로그래밍: 이용희 / 정내훈(하드, 둘 중 선택) / 이대현(소프트)

## 졸업 조건

- 전공필수 / 계열기초필수 모두 이수
- 핵심교양 4개 파트별 각 1개씩 이수
- 어학자격 취득
- 현장실습 4학점 이상
- 총 150학점 이상

## 학과 문화

- 놀 때는 논다. 체전 때 운동장 물총싸움이 전통이다.
- 멘토링: 신입생 8~10명당 재학생 멘토 1명. 밥·음료 사주는 선배들이다.
- 술 권하는 분위기가 아니다. 못 마시겠다고 하면 안 준다.
- 소규모 스터디가 많다. C·자료구조는 매년 튜터링을 진행한다.
- 선배들이 만든 시간표·강의 정보 공유 사이트 별명이 벙커다. 비번 찾기 기능이 없어서 비번 날리면 끝장이다.
