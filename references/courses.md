# 과목별 정리

선배 정리: 재학생이 후배들 보라고 정리한 과목별 팁 모음이다.
시험·팁 물어보면 여기서 답한다.

2015~2026 갤 글 기준. 연도가 붙은 항목은 그 시점 기준이니 학기마다 확인해라.

## 읽는 법

- 담당 교수 기준, 한 과목에 여러 교수가 있으면 분반·루트 선택 구조로 기록한다.
- 시험·팁 위주로 답할 때 인용하는 주 파일이다.
- 약자(장자료·송윈플·윈플·겜플·텀플)는 `professors.md` 맨 아래 참조.

## 1학년

### C언어

- 담당: 윤정현 / 김경철 / 장지웅(간혹)
- 김경철 분반 시험: OX + 손코딩. OX 오답 감점이라 모르면 비워둬라. 손코딩은 책·컴퓨터 없이 직접 작성, 들여쓰기 주의.
- 첫 강의의 F 엄포는 겁주기가 아니라 열심히 하라는 뜻이다.
- 2015 갤 후기 기준 김경철 분반은 F 비율이 높다는 말이 있다. OX는 아는 것만 체크하고 손코딩 들여쓰기까지 본다.

### C++프로그래밍

- 담당: 윤정현 / 천일용 / 이형구(엔컴·2-2)
- 천일용 분반: 한 학기 책 두 권(C++ → STL) 진도다. 강의는 좋으나 빠르고 따라가기 힘들다.
- 윤정현 분반: 수업 태도 엄격. 수시고사를 자주 보고 기말 형태가 특이하다(2015). `professors.md` 윤정현 참조.
- 이형구 분반: 중간·기말 없이 쪽지시험 4번 + 과제 1번(2018). C++ 문법 수업이다.

### 창의적 공학설계 (1-2)

- 담당: 김경철
- TRIZ 중심. 5~7인 조별 과제 매주 수행 + 텀 프로젝트. 발표 시간 엄수, 단어 사용 유의.
- 비프로그래밍이라 학점은 잘 주는 편이다.

### 전공입문 (1-1)

- 담당: 장지웅
- 토론식으로 진행해 참여가 중요하다. `professors.md` 장지웅 참조.

### 게임학기초 (1학년)

- 담당: 김경철
- 문명·스타크래프트·퍼즐앤고의 승리 조건을 시험에 낸다.
- 과제: 퍼즐앤고 점수 + 리뷰·증거 사진 제출.

## 2학년

### 자료구조 (2-1)

- 담당: 장지웅(장자료) / 이형구 — 루트별 선택 구조. 하드 루트는 장지웅, 소프트 루트는 이형구(이수과정 표기).
- 장지웅: 토론식, 참여 유도, 40여명/반, 끝까지 버티면 F 면함. 매주 코딩 수시고사 3~7문제. 과제 중 자료구조 기반 콘솔 오목(어떤 해는 오델로) AI 대결이 있다.
- 장지웅: 2시간 이론 + 2시간 실습. 실습은 롤 딕셔너리 같은 과제를 조교가 채점(2018). 기말에 희망자 F 면제 시험(2017). 포인터/C 기본이 없으면 버겁다.
- 이형구: 책 위주, 시험 3~4회, 마지막 프로그램 발표·시연.
- 이형구: 장지웅보다 덜 빡세서 코딩 자신 없으면 선택. 청강은 첫 수업만(2017).

### 윈도우 프로그래밍 (2-1)

- 담당: 송인희(송윈플)
- 매 시간 실습 2~4개·총 60여개, 매 시간 검사. 동그라미/세모/엑스로 채점한다. 중간 간단 게임, 기말 2인 1조 텀 프로젝트(게임 제작).
- 숙제는 초밥 만들기 게임, 지뢰찾기처럼 게임 하나를 완성하는 식이다.
- 자료구조와 병행하면 일주일 내내 실습이다.
- 1시간 이론 + 1시간 실습. 과제는 조교가 검사하고 기한 1~2주, 성적 직결. C/C++ 중 편한 걸로(2018).
- 과제량이 많아 "과제 요정" 소리. 학점 위해 피하는 사람도 있다(2018).

### 컴퓨터구조 (2-1)

- 담당: 주영배 / 김경철
- 주영배: 중간 책 절반, 기말 책 전체, 골고루 출제. 답안지 위 직접 채점 표기. 시험이 어렵고 80점 만점에 20/20이면 B+라는 후기(2015).
- 김경철: Logisim으로 CPU 회로. 매주 회로 과제, 중간·기말 이론 + 회로 그리기(2018).

### 그래픽스 (2-2)

- 담당: 송인희
- 매 시간 실습 2~3개·총 40~50여개. 중간 3D수학 + OpenGL, 기말 3D이론, 2인 1조 텀 프로젝트(게임 제작).
- 숙제: 사다리꼴 클리핑, 롤러코스터(브레젠험 + 스플라인) 구현이 나온다.

### 2D게임프로그래밍 (2-2)

- 담당: 정내훈 / 이용희 / 이대현 — 루트별 선택 구조.
  - 하드 루트: 정내훈·이용희 중 선택 (이수과정 표기)
  - 소프트 루트: 이대현
- 정내훈: DirectDraw → Direct2D → 2D엔진, 속도 빠름, 400~500점 만점, OX 감점, 텀 프로젝트 있음.
- 이대현: 파이썬 + pico2d, 3차 발표까지 게임 완성. 학점은 잘 주는 편이다.
- 이용희: Direct2D/C++로 진행한 해가 있다.

### 게임수학 (2-2)

- 담당: 김영식
- Bullet 엔진 기말 프로젝트. 중간·기말 수학, 자필 참고용지 1장 허용. 과제 + 텀 프로젝트에서 변별.
- 2015 갤 기준 중간·기말은 어렵지 않고 깜지 1장을 허용한다.

### 운영체제 (2-2)

- 담당: 오황석 / 정내훈(분반)
- 오황석: 1인 1과제(주제 선정 → 문서 작성 → 면담 검사). 수업 내 출제, 강조 부분 있음. 마감 몰림 주의.
- 오황석: 텀 프로젝트도 개인별 1:1 검사. 양식·설명이 허술하면 그 자리에서 까인다.
- 오황석: 리눅스 기반 운영체제기초는 출석+과제만 해도 B~B+ 무난(2015).
- 정내훈 분반은 시험·과제가 어렵다는 평(2017).

### 알고리즘 (2-2)

- 담당: 이재영 / 주영배
- 이재영: 오픈북, 책 위주, 실습 없음, 출장 휴강 가능.
- 주영배: 중간 책 절반·기말 책 전체, 골고루 출제. 시험이 어렵다는 평(2015).

### 3D모델링 (2학년)

- 담당: 김현
- 시범 후 따라하기. 그래픽 특강. 중간 모델링·기말 텍스처(변경 가능).
- 프로그래밍과 무관해서 부담이 적다(2018). 그래픽 지망이면 특강을 들어라.

## 3학년

### 3D게임프로그래밍1 (3-1)

- 담당: 이용희
- 한 학기 투자 각오. 구술시험 1:1 총 4문제(중간·기말 동일 방식). 2개 분반 70~80명. 35명으로 시작해 기말에 10명 내외만 남은 해도 있다.
- 2015 갤 기준 과제가 6개 나온다는 후기도 있다. 대표 과제는 아래 2개다. 이산수학과 같이 들으면 학기가 매우 빡세다.
- 편입생은 4-1에 듣는 걸 추천(2018).
- 과제 2개 정도:
  - ① 3D 그래픽스 이론으로 직접 만든 WinAPI 렌더러(DrawLine으로 투영된 씬 출력)로 간단한 게임 제작. 게임 주제는 매년 다름.
  - ② ①의 게임을 DirectX 12로 마이그레이션.

### 3D게임프로그래밍2 (3-2)

- 담당: 이용희
- 1개 분반 개설될까 말까, 10명 내외 폐강 위기 상시.
- 내용: 애니메이션 기초 + 그래픽스 심화.

### 네트워크 기초 (3-1)

- 담당: 김재경
- 중간까지 PPT 강의, 이후 4인 1조 발표. PPT가 영어라 해석 필요(2015). 레포트 주제는 TCP/IP, 핀테크 등(2018).

### 네트워크 게임 프로그래밍 (3-2)

- 담당: 김재경
- 실습 코드 원리 설명 필수. 과제 코드를 다음 시간에 왜 그렇게 동작하는지 질문하고, 만족할 답이 나와야 인정(2015). 성실하면 잘 봐준다. 학점 엄격.

### STL (3-1)

- 담당: 윤정현 / 이형구
- 윤정현 분반: C++17 이후 멀티스레드까지 반영. 수업이 꽉 차고 어렵지만 남는 게 많다(2017·2023).
- 이형구 분반: 시험 4회로 쪼개서 본다. 학생 이름·얼굴을 외워서 출튀가 어렵다. PPT·교재 예제 중심.

### 스크립트 언어 (3-1)

- 담당: 이재영 / 김영식
- 김영식 분반: 파이썬 문법 위주. 연습문제 과제, 중간 코딩, 기말 텀 프로젝트(공공데이터 XML 파싱, 2인 1팀, 발표 영상 3회)(2018).
- 이재영 분반: 2015 갤 후기 기준 학점은 나쁘지 않다. 시험 방식은 학기마다 확인해라.

### 게임인터페이스설계 (3-1)

- 담당: 임창주
- 매년 방식이 바뀌고 유니티로 무언가 만든다(2018).
- 포토샵/UI 디자인을 잘하면 기말이 꿀. 점수 잘 줌(2015 강의평).

### 인공지능 (3-2)

- 담당: 이형구
- 시험 3~4회 + 실습 과제 + 마지막 과제. 제출 유무로 변별.

### 데이터베이스 (3-2)

- 담당: 장지웅
- 자료구조와 수업 방식이 다르다. 시험 일정·강의자료는 수업에서 확인(2017).

## 졸작·종설 (2021년 이후)

후배들 기준 구조다. 학번에 따라 다를 수 있다.

- 3-2 종설기 → 4-1 종설 → 4-2 종설로 이어진다.
- 4-2 전 여름방학까지 팀을 꾸려 계속 굴려야 한다. 중간에 팀이 깨지면 4-2가 매우 힘들다.
- 졸작 점수는 상대평가다. 편입생은 랩실 출신 팀에 밀릴 수 있으니 팀 구성을 일찍 하라.
- 상용엔진으로 졸작하는 걸 두고 갑론을박이 있었다. “3D겜플 안 듣고 엔진으로 졸작하면 클라 자격이 없다”는 쪽과 “완성이 먼저”라는 쪽이 갈렸다.
