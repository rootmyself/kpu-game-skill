## 학부 구조 (2015년 기준)

- 게임공학과 + 엔터테인먼트컴퓨팅 학과로 구성.
- 게임프로그래밍, 미디어 융합 등 컴퓨팅 기술 + 실무 능력 배양이 목표.

## 학년별 과목 흐름 (2015년 기준)

### 1학년

- C언어 → C++ → 자료구조·윈도우 프로그래밍·컴퓨터구조로 이어지는 하드코어 루트.
- 1학년 C++ 강의는 진도가 매우 빠르다는 평이 있었다.
- 창의적 공학설계: 5~7인 조별 과제 + TRIZ 중심 + 텀 프로젝트, 발표 시간 엄수.

### 2학년: 장자료/송윈플 구간

2학년 1학기 `자료구조 + 윈도우 프로그래밍` 병행이 유명했다. 일주일 내내 실습에 치인다는 평.

- 윈도우 프로그래밍: 매 시간 실습 2~4개(총 60여개), 매 시간 검사. 중간고사는 간단한 게임 제작, 기말은 2인 1조 텀 프로젝트(게임 제작).
- 자료구조: 토론식 강의, 끝까지 살아남으면 F는 면한다는 평. 한 반 40여명 기준.
- 2학년 2학기 그래픽스: 매 시간 실습 2~3개(총 40~50여개). 중간·기말 모두 3D 이론 + 2인 1조 텀 프로젝트.
- 2D게임프로그래밍: DirectDraw부터 2D엔진 제작까지. 시험은 400~500점 만점, OX 오답 감점.
- 게임수학: Bullet 엔진 기말 프로젝트, 시험은 자필 깜지 1장 허용.
- 운영체제: 1인 1과제(주제 선정 → 문서 작성 → 교수님 면담 검사). 마감일 몰림 주의.
- 컴퓨터구조·알고리즘: 시험 범위 넓음(중간 책 절반, 기말 책 전체).

### 3학년: 진로 분기

- 3D게임프로그래밍1: 한 학기를 통째로 투자해야 한다는 평. 구술시험(교수님과 1:1, 총 4문제, 중간·기말 동일 방식). 3D겜플2는 수강생 10명 내외로 폐강 위기 상시.
- 네트워크 기초: 중간까지 PPT 강의, 이후 4인 1조 발표.
- 네트워크 게임 프로그래밍: 실습 코드를 "왜 그렇게 동작하는지" 설명해야 인정.
- STL, 스크립트 언어, 게임인터페이스설계, 인공지능, 데이터베이스.

### 4학년

- 게임서버, 서버프로그래밍, 모바일 게임 프로그래밍(iOS/Android), 게임엔진 프로그래밍, 가상현실게임, 전공특강.

## 이수 경로 밈 (2015년 기준)

하드하게 따르는 루트:

```text
C언어 → C++ → 자료구조(하드) + 윈플 + 컴구 → 2D겜플(하드) + 그래픽스 + 운영체제 + 알고리즘
```

소프트하게 따르는 루트: 자료구조·2D겜플 교수 선택을 바꾸는 버전이 있었다.

- 클라이언트: 3D겜플1 + STL + 네트워크 기초 → 네트워크 게임 프로그래밍 + 3D겜플2 → 전공특강 + 게임엔진
- 서버: STL + 네트워크 기초 → 네트워크 게임 프로그래밍 → 서버 프로그래밍

## 졸업 조건 (2015년 기준, 반드시 현행 확인)

- 전공필수/계열기초필수 모두 이수
- 핵심교양 4개 파트별 각 1개씩 이수
- 어학자격 취득
- 현장실습 4학점 이상
- 총 150학점 이상

## 학과 문화 (2015년 기준)

- 놀 때는 논다(체전 물총싸움 일화).
- 멘토링: 신입생 8~10명당 재학생 멘토 1명. 밥·음료 사주는 선배들.
- 술 권하는 분위기 아님. 못 마시겠다고 하면 안 줌.
- 소규모 스터디 다수. C·자료구조는 매년 튜터링 진행(수업조교 선배들이 모집).
- 강의평가 사이트(별명 "벙커") 존재. 비밀번호 찾기 기능이 없어서 비번 분실 주의가 밈.

## 스킬에서 쓰는 법

- 과목 고충 질문에 "2015년 선배 글 기준" 한 줄 맥락으로 활용. 예: "윈플 실습 60개 시절 얘기가 있는데, 지금도 비슷한가?"
- 시험·과제 팁은 시험 방식(오픈북/손코딩/OX 감점/구술) 중심으로만 인용.
- 교수 실명은 답에 쓰지 않는다. 과목명 + "옛날 글 기준"으로 일반화한다.
- 졸업요건·교육과정은 "바뀌었을 수 있으니 학과 홈페이지에서 해당 학년도 안내 확인"을 반드시 덧붙인다.
