## 1학년

### C언어

- 담당: 윤정현 / 김경철 / 장지웅(간혹)
- 김경철 분반 시험: OX + 손코딩. OX 오답 감점 → 모르면 비워두라는 팁. 손코딩은 책·컴퓨터 없이 직접 작성, 들여쓰기 주의.
- 첫 강의의 F 엄포는 겁먹지 말고 열심히 하라는 맥락(원문).

### C++프로그래밍

- 담당: 윤정현 / 천일용
- 천일용 분반: 한 학기 책 두 권(C++ → STL) 진도라는 소문. 강의는 좋으나 빠르고 따라가기 힘들다는 평.
- 윤정현 분반: 수업 태도 엄격. `professors-2015.md` 윤정현 참조.

### 창의적 공학설계 (1-2)

- 담당: 김경철
- TRIZ 중심. 5~7인 조별 과제 매주 수행 + 텀 프로젝트. 발표 시간 엄수, 단어 사용 유의.
- 비프로그래밍이라 학점은 잘 주는 편이라는 전언.

## 2학년

### 자료구조 (2-1)

- 담당: 장지웅(장자료) / 이형구 — 루트별 선택 구조. 하드 루트는 장지웅, 소프트 루트는 이형구(이수과정 표기).
- 장지웅: 토론식, 참여 유도, 40여명/반, 끝까지 버티면 F 면함.
- 이형구: 책 위주, 시험 3~4회, 마지막 프로그램 발표·시연.

### 윈도우 프로그래밍 (2-1)

- 담당: 송인희(송윈플)
- 매 시간 실습 2~4개·총 60여개, 매 시간 검사. 중간 간단 게임, 기말 2인 1조 텀 프로젝트(게임 제작).
- 자료구조와 병행 시 일주일 내내 실습이라는 평.

### 컴퓨터구조 (2-1)

- 담당: 주영배
- 중간 책 절반, 기말 책 전체, 골고루 출제. 답안지 위 직접 채점 표기.

### 그래픽스 (2-2)

- 담당: 송인희
- 매 시간 실습 2~3개·총 40~50여개. 중간 3D수학 + OpenGL, 기말 3D이론, 2인 1조 텀 프로젝트(게임 제작).

### 2D게임프로그래밍 (2-2)

- 담당: 정내훈 / 이용희 / 이대현 — 루트별 선택 구조.
  - 하드 루트: 정내훈·이용희 중 선택 (이수과정 표기)
  - 소프트 루트: 이대현
- 정내훈: DirectDraw → 2D엔진, 속도 빠름, 400~500점 만점, OX 감점.
- 이대현: 2014년 파이썬 스크립트 게임 전언, 학점 잘 주는 편.

### 게임수학 (2-2)

- 담당: 김영식
- Bullet 엔진 기말 프로젝트. 중간·기말 수학, 자필 참고용지 1장 허용. 과제 + 텀 프로젝트에서 변별.

### 운영체제 (2-2)

- 담당: 오황석
- 1인 1과제(주제 선정 → 문서 작성 → 면담 검사). 수업 내 출제, 강조 부분 있음. 마감 몰림 주의.

### 알고리즘 (2-2)

- 담당: 이재영 / 주영배
- 이재영: 오픈북, 책 위주, 실습 없음, 출장 휴강 가능.
- 주영배: 중간 책 절반·기말 책 전체, 골고루 출제.

### 3D모델링 (2학년)

- 담당: 김현
- 시범 후 따라하기. 그래픽 특강. 중간 모델링·기말 텍스처(변경 가능).
